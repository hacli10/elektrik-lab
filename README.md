# Elektrik Lab

Topraklama ve koruma rölesi konularında etkileşimli, öğretim amaçlı benzetimler (Türkçe). Tarayıcıda çalışır; hesap cihazın içinde yapılır,
ilk açılıştan sonra internet gerekmez. Telefonda: sayfayı açın → Paylaş → Ana Ekrana Ekle.

Bu depo yalnız derlenmiş siteyi içerir. Modeller sadeleştirilmiştir; bir tesisin uygunluğu proje hesabı ve ölçümle, bir rölenin ayarı onaylı
koruma koordinasyon çalışması ve üretici kılavuzuyla belirlenir.
